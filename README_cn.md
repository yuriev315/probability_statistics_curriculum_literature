# 概率与统计课程文献库

面向本科、硕士和博士阶段的概率论与数理统计学习资料：教材、论文、课程讲义、实践材料、案例和统计软件文档。

## 目录

- `books/`：教材与专著
- `papers/`：按主题分类的论文
- `courses/`：课程讲义与课程包（按课程群编号）
- `curricula/`：各校统计学培养方案与课程目录
- `practice/`：习题、实验和案例材料
- `software_docs/`：R、Python、Stan 等统计软件文档
- `projects_33/`：33 份带代码实践材料的运行依赖说明，用法见 `projects_33/README_cn.md`
- `scripts/`：资料库脚本与 arXiv 元数据缓存

课程包和超过 50 MiB 的文件在 Release `probstat-files-20261105` 和 `probstat-supplement-20261106` 中，Windows 运行依赖在 Release `probstat-resources-20261105` 中。把附件解压到仓库根目录即可。

## 清单

- `catalog_cn.csv`：全部条目总目录
- `files_cn.csv`：仓库和 Release 中的文件，含来源、许可和 SHA-256
- `release_excluded_cn.csv`：只提供 `.url` 链接的文件
- `pending_items_cn.csv`：已登记但暂未收录的条目

`.url` 文件在 Windows 上可直接双击打开，也可以用文本编辑器查看其中的地址。

## 许可证

只收录有明确再分发许可的文件，各文件保留其上游许可证，请按 `files_cn.csv` 中的条款使用，NC、ND 等限制仍然有效。未声明许可证的资料只提供链接。如果你是权利人并希望移除某个文件，请提 Issue。
